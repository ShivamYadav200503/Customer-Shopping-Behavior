# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview
This project analyzes customer shopping behavior using **SQL, PostgreSQL, Python, Excel, and Power BI**. The objective is to explore purchasing patterns, customer demographics, seasonal trends, and sales performance to generate actionable business insights through data analysis and interactive dashboards.

---

## 📊 Dataset
- **Records:** 3,900+ customer transactions
- **Source:** Customer Shopping Behavior Dataset
- **Features:**
  - Customer Demographics (Age, Gender, Location)
  - Product Category
  - Purchase Amount
  - Season
  - Payment Method
  - Discount Applied
  - Subscription Status
  - Review Rating
  - Purchase Frequency

---

## 🛠️ Tech Stack

- **SQL (PostgreSQL)** – Data querying and analysis
- **Python (Pandas, NumPy)** – Data cleaning and preprocessing
- **Microsoft Excel** – Initial data exploration
- **Power BI** – Interactive dashboard creation
- **Git & GitHub** – Version control
